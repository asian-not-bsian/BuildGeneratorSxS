How the calculator works
Optional formula and source details for players who want to inspect the calculations.




Damage
raw = ATK × coefficient + flat
armor layer = ATK / (ATK + DEF)
base damage = raw × armor layer

then apply: target skill reduction → elemental/physical layer → DMG Boost/RES → Crit OR Block → rank/level offsets → situational effects
EXACT STRUCTURE · ATK appears in both the skill base and armor layer.


Crit / Block
critChance = 5% + attacker Crit - defender Crit Avoid
critMultiplier = max(1.3, 1 + Crit DMG - enemy Crit Avoid)
Crit and Block are mutually exclusive.
EXACT STRUCTURE


Speed timeline
interval = 100000 / sqrt(SPD × rankSpeedScale)
turn-rate ratio = sqrt(yourSPD / enemySPD)  [same rank]
actions over N enemy turns = floor(N × sqrt(yourSPD / enemySPD))
next-action SPD ratio = ((N+1)/N)^2
EXACT


Effect application
chance = baseChance × (1 + EffectHit / BaseEffectRate)
         / (1 + EffectRES / BaseEffectDodge)

Abnormal-debuff rank correction is applied when the source/base tables require it.
EXACT STRUCTURE


Elemental / Physical layer
Element mult = [1 + Affinity/BaseElemAdd + Mastery/BaseElemMastery]
               / [1 + enemyAegis/BaseElemAdd + enemyElemRES/BaseElemMastery]

Physical uses the corresponding physical affinity/mastery/resistance bases.


Gear value equation
main = curve[level] × (1 + upgrade[+N]) × (1 + quality)
       (+ Season Enhancement while promotion matches)
secondary uses the same shape on its own curve.

# Restore BuildGeneratorSxS from this package

This folder is a complete repository snapshot, not a patch.

If the GitHub repository was accidentally overwritten, replace the repository contents with the contents of this folder. Do **not** upload this outer folder as a nested folder.

The repository root should contain files such as:

- `index.html`
- `assets/`
- `data/`
- `js/`
- `tests/`
- `.github/`
- `sw.js`
- `package.json`

After replacing the files, commit and push to `main`. GitHub Pages will redeploy through `.github/workflows/pages.yml`.
